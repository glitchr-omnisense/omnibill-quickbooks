# omnibill/quickbooks

**Reserved, not released yet.**

QuickBooks Online for omnisense/omnibill: journal entries and contacts in QuickBooks (OAuth 2.0; the Builder tier, production keys after Intuit's app assessment). The family's `journal-entries` and `contacts` contracts (`JournalEntriesInterface`,
`ContactsInterface`, since omnisense/omnibill 1.1) are what it will keep, as
[`omnibill/odoo`](https://github.com/glitchr-omnisense/omnibill-odoo) and
[`omnibill/pennylane`](https://github.com/glitchr-omnisense/omnibill-pennylane) do.

The name is kept for the provider package; nothing is released under it yet. A maintainer is
wanted: see the site's [contribute page](https://glitchr-omnisense.github.io/omnisense/contribute).
